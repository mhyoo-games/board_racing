# 바람보드 레이싱

하늘을 나는 보드를 타고 달리는 3D 웹 레이싱 게임. 점프대에서 뛰어 공중 묘기를 부리고, 판정(GOOD · NICE · EXCELLENT)으로 게이지를 모아 부스터를 써요.

**하기: https://mhyoo-games.github.io/board_racing/**

## 무엇을 할 수 있나

- **개인전** — 컴퓨터 7명과 경주. **팀전** — 4 대 4, 순위 점수(1등 10점 … 8등 1점)를 더해 많은 팀이 승리.
- **타임어택** — 혼자 달려 금·은·동 메달 따기.
- **친구와 온라인 (최대 8명)** — 방장이 방을 만들면 나오는 6자리 방 코드를 친구들이 넣으면 연결. 빈자리는 컴퓨터, 팀전도 가능.
- **스피드전 / 아이템전** — 아이템: 부스터·물풍선·끈끈이·먹구름·비눗방울·쿵쿵.
- **트랙 5개** — 새싹 언덕(나무 계단), 눈꽃 얼음길(미끄러운 얼음), 구름 섬 건너기(점프대로 낭떠러지 건너기), 버섯숲 지그재그, 성벽 위 8자 길(위아래로 엇갈리는 다리).
- **보드 상점** — 능력치(최고 속도·가속·핸들링·점프·묘기·부스터)가 다른 보드 11종. 레벨이 오르면 더 좋은 보드를 살 수 있고, 희귀 보드 3종은 경주 뒤 **행운 상자**에서만 나와요.
- **레벨·경험치** — 순위와 묘기 점수로 경험치를 받아 레벨이 올라요. 캐릭터 5명 중 고르고 이름을 정할 수 있어요.

## 조작

| | 키보드 | 게임패드 |
|---|---|---|
| 달리기 | ↑ 가속 · ↓ 브레이크 · ←→ 방향 | RT · LT · 스틱 |
| 슬라이드(급회전) | Shift | RB |
| 부스터 / 아이템 | Space · Ctrl | LB |
| **A 점프** | A | A |
| **S 그랩 · D 360 · F 720** | S · D · F | X · Y · B |

휴대폰은 화면 버튼(가속은 저절로). 멈춤: Esc 또는 P

## 점프와 묘기

- 점프대(나무 오르막) 위에서 **A**. 끝(노란 칸)에 가까울수록 GOOD → NICE → EXCELLENT, 더 높이 날아요.
- 공중에서 **S·D·F**로 묘기. 땅에 닿기 전에 끝나야 성공이고, 끝나자마자 닿을수록(아슬아슬할수록) 좋은 판정. 못 끝내면 MISS로 비틀거려요.
- 공중이 길면 GB + 360처럼 이어서 할 수 있고, 성공이 이어지면 콤보.
- 판정·슬라이드로 게이지가 차고, 가득 차면 부스터 +1(두 개까지). EXCELLENT로 착지하면 살짝 빨라져요.
- 계단은 덜컹덜컹 느려요 — 점프로 넘으세요.

## 만든 방법

- Godot 4.6 (GDScript, GL Compatibility) → 웹으로 내보내 GitHub Pages에 올린다.
- 규칙(보드 움직임·점프·묘기 판정·게이지·트랙 구간·순위·컴퓨터·상점·레벨·행운 상자·저장)은 `scripts/rules.gd`에 화면과 떨어뜨려 두고 `tests/run_tests.gd`로 확인한다. 테스트에서 컴퓨터가 모든 트랙을 점프·묘기하며 완주한다.
- 트랙은 `data/tracks.json`의 조절점을 곡선으로 이어 길·가장자리·점프대·계단·얼음·발판을 코드로 만든다. 보드는 `data/boards.json`의 모양 값으로 코드에서 조립한다.
- 소리와 곡은 `tools/sound/gen.py`가 코드로 합성한 새 곡이다 (음원 파일을 가져오지 않음).
- 친구와 온라인은 WebRTC로 방장 브라우저와 각 친구 브라우저가 바로 주고받는다(게임 서버 없음). 처음 연결 정보만 공개 메시지 중계 [ntfy.sh](https://ntfy.sh)에 잠깐 올려 서로 찾는다.
